# Adidas Sales Analysis Dashboard (Power BI)

## Project Overview

This Power BI dashboard analyzes Adidas sales performance across different regions, products, retailers, and states. The dashboard provides interactive insights using KPIs, trend analysis, maps, and visualizations to support business decision-making.
